# Founders Inflections

This is a public static newsletter archive hosted on Vercel.

- Build with Node built-ins: `npm run build`. No dependency install is required.
- Run `npm test` to check archive navigation and escaping.
- Canonical issues live in `content/YYYY-MM-DD.json`; preserve previous issues.
- Matching Word editions live in `public/downloads/YYYY-MM-DD.docx`.
- Follow `editorial.md` for future issues.
- Never include credentials, private conversations, local paths, or unrelated documents in public files or Git history.
- Build output is `dist`; Vercel settings are in `vercel.json`.
- The previous Sites checkout is separate. This repository does not control its deployment.
